
# ಶಿಕ್ಷಣ ಇಲಾಖೆ ನೌಕರರ ಸಹಕಾರ ಸಂಘ, ಚಿಕ್ಕನಾಯಕನಹಳ್ಳಿ

## ನಮ್ಮ ಸಂಘದ ಪರಿಚಯ
ಶಿಕ್ಷಣ ಇಲಾಖೆ ನೌಕರರ ಆರ್ಥಿಕ ಮತ್ತು ಸಾಮಾಜಿಕ ಅಭಿವೃದ್ಧಿಗಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿರುವ ಸಹಕಾರ ಸಂಘ.

## ನಮ್ಮ ಉದ್ದೇಶಗಳು
- ಸದಸ್ಯರಿಗೆ ಆರ್ಥಿಕ ನೆರವು ನೀಡುವುದು.
- ಉಳಿತಾಯ ಮತ್ತು ಠೇವಣಿಗಳನ್ನು ಪ್ರೋತ್ಸಾಹಿಸುವುದು.
- ಸದಸ್ಯರ ಕಲ್ಯಾಣಕ್ಕಾಗಿ ಕಾರ್ಯಕ್ರಮಗಳನ್ನು ಆಯೋಜಿಸುವುದು.
- ಶಿಕ್ಷಣ ಮತ್ತು ಸಾಮಾಜಿಕ ಚಟುವಟಿಕೆಗಳಿಗೆ ಪ್ರೋತ್ಸಾಹ ನೀಡುವುದು.

## ನಮ್ಮ ಸೇವೆಗಳು
- ವೇತನ ಸಾಲ
- ಆಧಾರ ಸಾಲ
- ಠೇವಣಿ ಸೌಲಭ್ಯ
- ಸದಸ್ಯರ ಕಲ್ಯಾಣ ಕಾರ್ಯಕ್ರಮಗಳು
- ಪ್ರತಿಭಾ ಪುರಸ್ಕಾರ

## ವೆಬ್‌ಸೈಟ್ ವಿಭಾಗಗಳು
- ಅಧ್ಯಕ್ಷರ ಸಂದೇಶ
- ಸಂಘದ ಪರಿಚಯ
- ಆಡಳಿತ ಮಂಡಳಿ
- ಸಾಲದ ವಿವರಗಳು
- ಪ್ರಕಟಣೆಗಳು
- ಸಂಪರ್ಕ ಮಾಹಿತಿ

## ಸಂಪರ್ಕ
ಶಿಕ್ಷಣ ಇಲಾಖೆ ನೌಕರರ ಸಹಕಾರ ಸಂಘ,
ಚಿಕ್ಕನಾಯಕನಹಳ್ಳಿ, ತುಮಕೂರು ಜಿಲ್ಲೆ.
